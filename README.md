# KrishiSetu: Market Linkages & Price Discovery Platform
**Team ID / SIH 2026 Problem Statement ID:** 26132  
**Theme:** Agriculture, FoodTech & Rural Development  
**Organization:** Government Of Maharashtra (Maharashtra State Innovation Society)

## 🚀 Problem Statement
Smallholder farmers lack visibility into real-time mandi prices, quality grading norms, and verified buyers, leading to distress sales and heavy post-harvest losses.

## 💡 Our Solution
KrishiSetu is an integrated market-intelligence and transaction enablement platform that bridges the gap between farmers/FPOs and institutional buyers by offering:
- Real-time Mandi Price Aggregation & Trend Analysis.
- AI/Rule-based Sale-Window Recommendations.
- Digital Lot Creation & Quality Grading Verification.
- Seamless Bidding, Logistics Coordination, and Secure Payment Tracking.

## 🛠️ Tech Stack
- **Frontend:** React.js / Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
